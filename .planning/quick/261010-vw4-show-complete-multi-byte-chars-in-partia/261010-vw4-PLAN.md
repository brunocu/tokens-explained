# Quick 261010-vw4: Show complete multi-byte chars in partial chip frame label

Gap: a partial token like "の国" (E3 81 AE E5 9B) holds a complete character (の) plus the first
bytes of a split character (国). `groupBytes` builds frame labels from split characters only, so the
label shows 国 and never の.

## Task
1. `src/core/chars.ts` (`groupBytes`): frame labels = split characters plus complete multi-byte
   characters whose first byte lies in the frame's tokens, in byte order. Invalid-only frames keep
   the "invalid" label.
2. `src/core/chars.test.ts`: add a test for "の" + first two bytes of "国" (label order の, 国).
3. Run vitest.
