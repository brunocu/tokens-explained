## Goal

A non-programmer reads a post in which every split they see is a real GPT-2 split, the bridge from the miniature stepper to GPT-2 is explicit, the id difference is explained in one sentence, and the reason for choosing an old tokenizer is honest and cited.

Source: D-02, D-10, D-11, D-12, D-13, D-14, D-15, D-18; RESEARCH G2, G3, G8; EVALUATION sections 4 and 8.

## Flagged assumptions and planner choices

- Planning brief resolved the open questions: use a new GPT-2 fact source (`gpt2Facts.ts`) for D-13; if new prose exceeds the 2,750-word ceiling, raise the ceiling in the same change with a recorded rationale (measured 2,566 words before this plan; the stale "2671" comment in the content test is corrected).
- The figure component is renamed `TokenFigure` (Claude's discretion under D-11). A boolean prop `sample` makes it cut the stepper's own SAMPLE_SENTENCE constant (not typed by hand) and puts `data-figure="sample"` on the figure so e2e tests can tell the three figures apart.
- A new claim `every-word-one-token` backs the sentence "a token for every word of this sentence", so the bridge cannot go stale (D-11).
- The `LANGUAGES_SLOT_SENTENCE` ("three tokenizers") is NOT changed here; it changes together with the table in plan 02.1-05.
- D-14 names "digits, non-English" as examples of newer models cutting text differently. Digits are verified from the cited source on 2026-10-06 (tiktoken `openai_public.py`: the GPT-2 split rule matches a whole run of digits, while the cl100k rule matches digits in groups of at most three). A claim about non-English text has no source in the project's reference list: the executor may add it only if a primary source on an allowed link host (see `ALLOWED_REFERENCE_LINK_HOSTS` in scripts/check-dist.mjs) is found through the quick-search subagent; otherwise the post says only that newer models cut text differently, for example digits, and the SUMMARY records the gap.
- Web research for D-14 is delegated to the `quick-search` subagent (project rule: no web fetches in the main context).
- The licence wording is "permissive MIT-style licence" (the hosted file's repo ships OpenAI's "Modified MIT License"), per RESEARCH G8; never a bare "MIT" and never a comparison with newer tokenizers' licences.
