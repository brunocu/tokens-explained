## Independent retry behaviour of the two islands

The playground and the own-text block each call `loadTokenizer("gpt2", baseUrl)` on mount. When the file loads, both share one request (the privacy spec pins exactly one). If it fails, the loader evicts the entry, and each island keeps its own error state and its own Try again button. Pressing one island's Try again makes a new request and, on success, the loader's memo holds the file, so the other island's Try again then resolves with no request (the (c2) spec asserts this). If both islands called the loader before the first failure, they share that one failed attempt. Unifying the two states is out of scope.
