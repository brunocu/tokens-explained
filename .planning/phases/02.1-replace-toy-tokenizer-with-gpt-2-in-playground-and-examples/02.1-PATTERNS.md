## Pattern Assignments

### `src/core/buildTokenizer.ts` (new; Node-only GPT-2 for frontmatter, claims tests, scripts)

**Analog:** RESEARCH G2 recipe (prototype-built this session) over the adapter in `src/core/realTokenizer.ts`. Copy the recipe verbatim:
```ts
import { readFileSync } from "node:fs";
import { createRealTokenizer } from "./realTokenizer.ts";
import type { RealTokenizer, TokenizerCtor } from "./realTokenizer.ts";
let memo: Promise<RealTokenizer> | undefined;
export function buildGpt2(): Promise<RealTokenizer> {
  memo ??= (async () => {
    const json = JSON.parse(readFileSync(`${process.cwd()}/public/tokenizers/gpt2.json`, "utf8")) as object;
    const { Tokenizer } = await import("@huggingface/tokenizers");
    return createRealTokenizer("gpt2", json, Tokenizer as unknown as TokenizerCtor);
  })();
  return memo;
}
```
Use `process.cwd()`, not `import.meta.url`. Dynamic import only (never top-level) per CLAUDE.md. Never imported from an island.
