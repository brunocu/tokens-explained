## Phase Goal

**As a** reader with no programming background, **I want** the page to run two real tokenizers in my browser, **so that** I can see how real models cut the same text differently, with no data leaving my computer.

Source: ROADMAP Phase 2 criterion 3, D-08 to D-11. This plan builds the engine side only (files, dependency, adapter, parity); the reader-visible comparison is plans 02-05 to 02-08.

## Flagged assumptions

- RESEARCH A2/A3: shipping the Apache-2.0 text, the OpenAI MIT notice and an attribution satisfies the licences. This is not legal advice. Task 1 asks the user to confirm it once.
- The GPT-2 repo has no LICENSE file; MIT comes from the model-card front matter and the upstream openai/gpt-2 licence ("Modified MIT", copyright 2019 OpenAI). NOTICE.md says so plainly.
