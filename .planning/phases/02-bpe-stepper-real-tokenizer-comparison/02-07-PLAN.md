## Phase Goal

**As a** reader with no programming background, **I want** to see one sentence in several languages and how many pieces each tokenizer needs, **so that** I understand that the same meaning can cost very different numbers of tokens.

Source: ROADMAP criteria 4 and 5, D-14, D-15 (table with bars plus optional look-inside), UI-SPEC section 3 as amended by R-02, TOK-08, TOK-09.

## Flagged assumptions and planner choices

- A1 (plan 02-01): the sentence is the whole of Article 1, not "first sentence"; the visible source line and details say "Article 1".
- A2 (plan 02-01): the count cell's UNK text line "{k} of these are [UNK]" is a UI-SPEC R-02 addition.
- UI-SPEC says the look-inside loading line points "below" and the failed line "above"; the table sits above the picker, so both lines say "above" (planner correction).
- The table is static HTML in an Astro component; only the look-inside picker is an island. The UI-SPEC name `LanguagesDemo.svelte` is kept for that island and `LanguagesTable.astro` is added for the static part.
- OHCHR asks for attribution with a link, so the visible source line links to `SOURCE_PAGE`; `check-dist` gets an anchor-only host allow-list for www.ohchr.org and www.un.org (Task 2).
