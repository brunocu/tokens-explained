## Goal

Finish the playground: neutral lifecycle wording, migration of every spec that drove the removed toggles, the height-across-states proof in three browsers, and the measured final height.

Source: D-01, D-02, D-08, D-09, D-10, D-14; UI-SPEC "1. Playground", "Lifecycle, Status and Neutral Wording", "Verification Hooks" 1 and 8, "Test impact"; RESEARCH G-3 and Pitfall 6.

## Flagged assumptions and planner choices

- The height-across-states test reads the declared `--widget-h` from the root's computed style and compares the measured border-box height with it, so states that need a different page load (tokenizer loading, download failed, island never hydrated) can be checked without carrying a number between tests.
- The "island never hydrates" state is produced by aborting the playground script request; the 8-second watcher then sets the failed state, as the existing lifecycle test does.
- Test (e) in `e2e/frames.spec.ts` used byte lines on whole chips to prove which characters the four whole chips hold; it is rewritten to prove the same thing from the text and ID lines (the table alternative already carries the bytes).
