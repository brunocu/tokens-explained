## Decisions Made

- The import rule rejects any `import ` line that is not a plain default or named import from a double-quoted path, so a side-effect import or a multi-line import cannot slip through.
- `checkWidgetsHtml` requires the `data-six-texts` details element as well as the six items, since that hook name was fixed by this plan.
- The helper `expectStacked` requires at least two `.widget-col` elements for plain two-column widgets and at least one for the languages widget. If plan 02.2-06 puts its full-width band outside any `.widget-col`, it may need to adjust only that registry flag or the column lookup.
