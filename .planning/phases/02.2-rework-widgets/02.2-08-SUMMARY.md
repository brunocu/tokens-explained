# Phase 02.2 Plan 08: Stacked layout gap closure Summary

Comparison rows no longer collapse and overlap below 1024px, and the languages table gives each sentence a full-width line of its own, with the 1024px+ layouts unchanged.

## Accomplishments

- **G-02.2-1a (Task 1, tracer).** The fill/subgrid rules in `TokenRows.svelte` were unconditional; stacked, the card has no definite height so the `1fr` tracks collapsed. They now live in `@media (min-width: 1024px)`. Below it the rows are ordinary blocks with the existing 24px gap.
- **G-02.2-1b (Task 2).** Below 1024px (`max-width: 1023.98px`) each `tr` is a 4-track grid: name plus Bytes, GPT-2, BERT on the first line, the sentence cell spanning all tracks on the next. `min-width: 480px` and the `width: 1%` / `nowrap` rules are overridden there. Explicit `role` attributes (`row`, `columnheader`, `rowheader`, `cell`) keep table semantics; the `Text` header is visually hidden but stays in the accessibility tree. All `data-*` hooks, `lang`, `dir`, copy and `check-dist.mjs` are untouched.
- **Spec (Tasks 1 and 2).** `e2e/stacked-layout.secondary.spec.ts` (390px, phone project, non-gating) checks both widgets. It was seen red before each fix.
